# AI Image Generator

A simple AI Image Generator website made using HTML, CSS, JavaScript, and API integration.
Users can enter a prompt, choose a model, select image count and ratio, then generate AI images instantly.

## Features for now
1. Dark and light mode can be switch by a button.
2. Random prompt generate by clicking the dice button.
3. Can select Ai model.
4. Can select image count.
5. Cna selecct image ratio.
etc.
