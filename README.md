# AI Image Generator

A simple AI Image Generator website made using HTML, CSS, JavaScript, and API integration.
Users can enter a prompt, choose a model, select image count and ratio, then generate AI images instantly.

## Features
Clean and simple design
Dark and Light theme toggle
Generate AI images using prompts
Select different AI models
Choose image count
Select image ratio
Responsive layout
Easy to use interface

## Technologies Used
HTML
CSS
JavaScript
API
